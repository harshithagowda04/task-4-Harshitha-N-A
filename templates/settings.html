Configuration, methodology and privacy details for this local installation.

APPLICATION

PhishGuard

Phishing Awareness & Email Threat Analysis System

VERSION1.0.0
PROJECTCyber Security Project 3
PROGRAMDecodeLabs · Batch 2026
TECHNOLOGY

Local-first stack

Python, Flask, SQLite, HTML, CSS and JavaScript. Charts use Chart.js; icons use Font Awesome.

Detection uses explainable static rules. There are no paid APIs, remote AI services or URL reputation requests.

METHODOLOGY

Weighted heuristic rules

Independent warning groups contribute bounded points. Duplicate rule groups are counted once; final values are capped at 100. More than one strong signal is required for a PHISHING verdict.

Threat classifications: LOW 0–24 · MEDIUM 25–49 · HIGH 50–74 · CRITICAL 75–100.

PRIVACY

Local analysis, local history

Submitted message text is stored in the local SQLite database to provide history and reports. Keep access to this computer and database restricted.

URLs are parsed as text only. Attachments are never accessed. Do not paste real secrets or passwords into training tools.

HEURISTIC EDUCATIONAL TOOL

Signals guide attention; context matters.

A low risk score does not prove a message safe, and a high score is not a forensic conclusion.
